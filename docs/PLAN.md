# Планер Миланы — ТЗ и решения

Личный PWA-планер для одного пользователя. Вход по почте, синхронизация телефон ↔ компьютер,
интерфейс на русском, mobile-first, на широком экране неделя целиком.

Сферы жизни: работа в MIMAY, администратор в онлайн-школе английского, учёба (журналистика, заочно),
тренировки, языки (испанский, английский, турецкий), личное.
Без помодоро и принудительных циклов.

## Принятые решения

- Отдельный репозиторий `planner-milana` (старый `-speakify` не трогаем).
- Стек: React + Vite + TypeScript, PWA, offline-first.
  - Локальная база Dexie (IndexedDB) — источник правды; облако — только синхронизация.
  - Слой данных за интерфейсом-адаптером, бэкенд заменяемый.
  - Основной кандидат — Supabase (auth, БД с RLS, storage). Запасной — PocketBase на российском VPS
    (Timeweb/Selectel, ~200–400 ₽/мес). Выбор — по результатам `check/`.
  - Хостинг: GitHub Pages (проверяется страницей `check/`).
- Вход по 6-значному коду из письма (OTP), не magic link (на iPhone ссылка открывается в Safari, а не в PWA).
  Регистрация для чужих закрыта, RLS — доступ только владельцу. Секретные ключи в код не кладём
  (в браузере только публичный anon-ключ, защита — через RLS).
- Телефон: iPhone (iOS 27). Web push работает только в PWA, установленной на экран «Домой»,
  и требует сервера-отправителя.
- Неделя начинается с понедельника.
- Просроченные задачи остаются на своём дне до вечернего разбора; автоматически ничего не переносится.
- «Последний рабочий день месяца» = последний будний день (Пн–Пт), праздники не учитываются.
- Привычки — только галочки, без чисел.
- Шкала часов в виде «День» настраивается (с какого по какой час).
- Категории внутри дня: у каждого дня свой набор, названия вводятся вручную («+ категория»),
  можно переименовать/удалить, перетаскивать задачи между категориями; задачи без категории — сверху.
  Внутри категории: без времени — списком, со временем — по времени. Это отдельно от «сфер» (цветных меток).

## Функции

1. **Задачи**: название, дата или без даты, время начала/конца (необязательно), сфера, заметка, «сделано»,
   повторы (каждый день; по дням недели; раз в N недель; раз в месяц — число или «последний будний день»),
   напоминание (push, только если включено), необязательный таймер старт/стоп.
2. **«Неделя»** (главный экран): «Фокус недели» (2–3 цели + мудборд); 7 дней с категориями, задачами,
   заметкой дня, привычками; drag & drop между днями (и на телефоне); листание недель.
3. **«День»**: выбор даты, задачи без времени списком, со временем — на шкале часов, заметка, привычки, стикеры;
   можно сделать стартовым экраном.
4. **«Когда-нибудь»**: задачи без даты, назначить/перетащить на день.
5. **Привычки**: свои, с днями недели; галочки; видны в неделе и дне; статистика за неделю/месяц.
6. **Вечерний разбор**: время настраивается; по каждой невыполненной — на завтра / на другой день /
   в «Когда-нибудь» / удалить.
7. **Планирование недели**: день настраивается; шаг 1 — итоги прошлой недели; шаг 2 — фокус, цели, мудборд;
   шаг 3 — раскидать «Когда-нибудь» и невыполненное по дням.

## Этапы

0. Проверка доступности сервисов (`check/`) + стиль (выбран «Шалфей»).
1. Каркас: проект, вход по коду, база, PWA, деплой, offline-first основа.
2. Задачи, сферы, категории дня, «Неделя», «День», «Когда-нибудь».
3. Повторы, привычки.
4. Вечерний разбор, планирование недели.
5. Темы (пастельные + своя), свои SVG-стикеры + загрузка PNG, мудборд.
6. Напоминания, таймер, полировка офлайн-синхронизации.
